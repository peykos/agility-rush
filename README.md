# Agility Rush — Human Edition

Play: https://peykos.github.io/agility-rush/

A single-player 3D agility race built with Babylon.js. You race against three computer-controlled human athletes through ten obstacle stations. The winner has the lowest running time plus penalties.

## Play on a phone

Open the link in Chrome or Safari, then press **ENTER THE ARENA**. Landscape orientation is recommended. No installation, account, ZIP extraction or local server is required.

- Left / right: steer and weave.
- JUMP: tap to jump.
- DUCK: hold while passing through tunnels.
- SPRINT: hold to run faster while energy remains.
- Each missed obstacle adds three seconds.

Keyboard: arrow keys or A/D to steer, Space to jump, Down or S to duck, Shift to sprint, P to pause, C to change camera.

## Hosting and privacy

This repository is the public static distribution. GitHub Pages serves the HTML, CSS, JavaScript and bundled engine. The original phone and Termux do not need to remain online.

Internet access is needed to load the page and its files. After loading, gameplay runs in the browser; personal bests are stored in that browser's local storage. The game contains no advertising, analytics or account system. GitHub may log requests as the hosting provider.

Local server code, developer verification scripts, test reports, screenshots and personal files are intentionally excluded from this repository.
